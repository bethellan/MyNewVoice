v148_topic_editor_cards

Main menu topic editing now uses responsive stacked cards instead of the old wide table.

The old green autosave indicator element/styles were removed so view changes no longer show the stray Saved popup.
Includes v147 iPhone scale/switch fixes and v146 editor viewport guards.
