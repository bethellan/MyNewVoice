About MyNewVoice

MyNewVoice was created by Andrew Bethell for his father after a stroke, to support clearer communication and help him stay connected with family, friends and everyday life. Early communication tools did not quite fit his needs, so the app has slowly been adapted to feel more local, personal, familiar and respectful of local culture.

Using the app

Tap a picture or phrase to show the message. If spoken voice is on, the device also speaks it aloud.

Use the view button in the top bar to switch between List, Menu and Grid views.

Top bar

The green switch turns editing on after the password is entered. The red switch turns Te Reo mode on or off. The view button cycles List, Menu and Grid. The question mark opens this Help screen. The cog opens Settings.

Display and touch

Theme is currently kept on Classic for a consistent public version. Yes / No quick buttons adds two large quick replies below the top bar.

Voice and speech

Spoken voice turns device speech on or off. When it is off, the large message stays on screen until tapped, so the user can show it to someone else.

Voice style asks the device for a default, male or female voice. Voice choice lets you pick a specific installed voice. Preview tests that selected voice. Speech speed and pitch adjust how phrases sound.

Content editor

Open Content Editor to change menu topics, phrases, photos, fallback icons, Te Reo wording, pronunciation wording and recorded voices.

When edit mode is on, hold a button on the main screen to edit, move or delete it. When edit mode is off, editing choices are hidden so the communication screen stays simple.

Grid view

Grid view shows one section at a time with large picture tiles. Swipe left or right to move between sections. The arrows can also move between sections.

Photo Memories

Photo Memories are for family photos and special pictures. A photo opens large and stays open until tapped. While open, it can be pinched to zoom and dragged around.

Backup and restore

Use Export Backup before large edits or before moving to another device. Import Backup restores words, settings, photos and recordings.

Offline use

Save Offline asks the browser to cache the app files on this device. That means the app can still open when there is no internet, as long as the browser keeps its saved site data.

Check Offline checks whether the main app files are saved. After publishing a new version, open the app online, use Save Offline, then test once with Wi-Fi or mobile data off.

Storage and backup size

Check Storage shows how much space photos, recorded voices and local app data use. It can also show unused media that is no longer attached to a current button.

Compress Photos keeps good quality but reduces file size. Make Photos Smaller reduces backups further with lower quality. Make Photos Tiny makes the smallest backups, but images will look softer.

Test tools

Test Speech checks whether this device can speak a simple phrase using the current speech settings. Preview in Voice and Speech is for checking one selected voice; Test Speech is a general sound check.

Test Photos and Voices checks that saved photos and recorded voices can still be found on this device after editing, importing or updating.

Advanced / Clear Device Data

Use this carefully. Remove Unused Media deletes images or recordings that are not linked to a current button. Remove All Images deletes pictures from this device. Remove All Audio deletes recorded voices from this device.

Export a backup before using these buttons, because cleared device data cannot be recovered unless it is in a backup.

Information

Information shows the app version, copyright, backup size summary, storage summary and offline readiness. It is useful before sending a backup or checking whether a device has the latest version.

Quick troubleshooting

If speech is silent, check device volume, mute/silent mode, and that Spoken voice is on in Settings.

If buttons do not feel right after an update, close and reopen the app, then use Update App from Settings.
